# GPU install

The Python environment must get a CUDA-enabled PyTorch build first. Do **not**
rely on the generic `pip install torch` line if you specifically want CUDA.

Use the official PyTorch installer selector for your OS, Python, and CUDA
choice, then install this project via `pyproject.toml`'s `gpu` extra
(replaces the old standalone `requirements-portable.txt`, which has been
folded into `pyproject.toml` — see the Foundation phase of the consolidation
review for why).

## Windows 10/11 PowerShell

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
python -m pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128
python -m pip install -e ".[gpu,qwen]"
python -c "import torch; print('CUDA available:', torch.cuda.is_available())"
```

## Linux bash

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -U pip
# Install the CUDA-enabled PyTorch command generated by the official PyTorch selector here.
python -m pip install -e ".[gpu,qwen]"
python -c "import torch; print('CUDA available:', torch.cuda.is_available())"
```

## Run the engine (CLI)

The old standalone `legal_rag_engine.py` / `check_gpu.py` scripts have been
removed as part of consolidating on `src/legal_ai/` as the single canonical
implementation (see the architecture review report). Use the package's CLI
entry point instead:

```bash
legal-rag --documents "legal_documents.json" --output artifacts_portable --query "ما شروط القبض في حالة التلبس؟"
```

For more VRAM:

```bash
legal-rag --dense-batch-size 64 --rerank-batch-size 64
```

For less VRAM (e.g. the 4GB Quadro M2200 dev target):

```bash
legal-rag --dense-batch-size 8 --rerank-batch-size 8 --precision fp16
```

For a first speed benchmark, keep `--compile-reranker` OFF. After the
baseline is stable, benchmark again with it enabled.
